# H · prévia pública para celular

Esta cópia contém somente HTML, CSS e uma ilustração fictícia. O código do
aplicativo e seus dados ficam no repositório privado do projeto.

As telas mostram dados de exemplo. Os formulários não enviam informações e o
site não cria contas nem consulta preços reais.

Abra `index.html` para ver a prévia ou `avaliar.html` para registrar um
comentário local e copiá-lo para a conversa do projeto.
