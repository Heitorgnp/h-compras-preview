# H · prévia pública para celular

Esta cópia contém somente HTML, CSS e fotos reais de referência com créditos. O código do
aplicativo e seus dados ficam no repositório privado do projeto.

As telas usam nomes de produtos selecionados da lista enviada pelo Heitor e fotos de
referência. Os preços e lojas da demonstração são fictícios. Fotos não confirmam
modelo, compatibilidade nem oferta. Os formulários não enviam informações e o
site não cria contas nem consulta preços reais.

Abra `index.html` para ver a prévia ou `avaliar.html` para registrar um
comentário local e copiá-lo para a conversa do projeto.
